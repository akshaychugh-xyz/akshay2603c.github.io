# uses this

A running list of the hardware and software I actually use day to day. Inspired by [uses.tech](https://uses.tech).

- **Laptops:** M3 MacBook Pro (personal) and M1 MacBook Pro (work)
- **Monitor:** [Lenovo](https://www.amazon.in/dp/B09FTFTVC2)
- **Keyboard:** [Keychron K2 Pro](https://www.keychron.com/products/keychron-k2-pro-qmk-via-wireless-mechanical-keyboard)

- **Floor lamp:** [Homecentre Kyoto Study Metal Floor Lamp](https://www.homecentre.in/in/en/Decor/Lighting/Floor-Lamps/HOMECENTRE-Kyoto-Study-Metal-Floor-Lamp/p/1000015317583)

- **Phone:** Pixel 9
- **Earbuds:** Pixel Buds
- **Watch:** Garmin Fenix 6
- **Reading:** Kindle. Book notes go on a paper notepad while I read, then get typed up later.

## Software

The list is short on purpose. Each one earns its place by getting used almost daily.

- **Launcher:** [Raycast](https://www.raycast.com). Window management, clipboard history, snippets, calculator, the lot.
- **AI coding (main driver):** [Claude Code](https://claude.com/claude-code) on the Claude Max $100 plan. Single biggest leverage upgrade in my workflow over the last year. I have a running log of how I level it up: [How to level up with Claude Code]({{ '/writings/png/how-to-level-up-with-claude-code' | relative_url }}).
- **AI editor:** [Cursor](https://www.cursor.com), with a custom rules file. Full writeup of how I use it as a non dev: [How I use Cursor]({{ '/writings/png/cursor' | relative_url }}).
- **Editor and terminal:** [VS Code](https://code.visualstudio.com) with [iTerm2](https://iterm2.com) for the shell. Claude Code runs in iTerm, not in the VS Code extension.
- **Notes and second brain:** [Obsidian](https://obsidian.md). Everything I think, capture, or write lives here first.
- **Spaced repetition:** [Anki](https://apps.ankiweb.net). Cards are auto generated from selected Obsidian notes so the retention layer does not depend on willpower.
- **Tasks:** [Todoist](https://todoist.com)
- **Issue tracking:** [Linear](https://linear.app)
- **Programmatic video and reels:** [Remotion](https://www.remotion.dev)
- **Product analytics:** [PostHog](https://posthog.com)
- **Mac power tool:** [Swiss Knife](https://swissknife.app) for quick conversions and formatting.
- **Passwords:** [Bitwarden](https://bitwarden.com)
- **Music:** [Spotify](https://www.spotify.com) and [YouTube Music](https://music.youtube.com)
- **This blog:** [Jekyll](https://jekyllrb.com) on [GitHub Pages](https://pages.github.com).

## Fitness

- **Yoga mat:** keeps me honest on stretching days.
